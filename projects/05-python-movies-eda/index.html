Project

Movies Data Analysis

Done at: upGrad Business Analyst Program (NSDC) · 2024Tools: Python, Pandas, NumPy, Jupyter

Problem
Find what makes movies successful with critics and audiences, using an IMDb dataset of 5,000+ films.
Result
Family + Sci-Fi earns the most on average, James Cameron has two films in the top 10 by profit, and Leonardo DiCaprio leads both the critic and audience lists among the actors compared.
StepsCode

How I did it

Step by step

  1. Loaded and inspected the data: 5,043 films and 28 columns.
  2. Cleaned it.Dropped unneeded columns and mostly-empty rows, filled missing languages, and removed duplicates. About 77% of rows remained.
  3. Found the most profitable filmsby subtracting budget from gross.
  4. Built an IMDb Top 250of films with more than 25,000 votes.
  5. Compared directors, genres and actorsto see who and what scores and earns best.

Python

Key steps in code

A short sample from the notebook.

Cleaning

Measured how much data was missing, then removed rows that were mostly empty.

# share of missing values in each column
round(100 * (movies.isnull().sum() / len(movies.index)), 2)

# drop rows with more than five missing values
movies = movies[movies.isnull().sum(axis=1) <= 5]

Most profitable films

Added a profit column and sorted to get the top 10.

movies['profit'] = movies['gross'] - movies['budget']
top10 = movies.sort_values(by='profit', ascending=False).iloc[:10]

Most popular genre pairs

Split each film’s genres and averaged box-office takings for each pair.

movies['genres'] = movies['genres'].str.split('|')
movies['genre_1'] = movies['genres'].apply(lambda x: x[0])
movies['genre_2'] = movies['genres'].apply(lambda x: x[1] if len(x) > 1 else x[0])
PopGenre = movies.groupby(['genre_1', 'genre_2'])['gross'].mean().sort_values(ascending=False)
